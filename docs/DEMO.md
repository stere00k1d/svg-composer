# Видеодемонстрация — 60–90 секунд

Перед записью: запустить редактор, закрыть лишние окна, использовать масштаб браузера 100%. Файлы примеров — в `examples/`. Не открывать общий файл работодателя и не публиковать запись без согласования.

| Время   | Действие                                                                 | Короткий комментарий                                                                                  |
| ------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| 0–10 с  | Показать библиотеку и ввести «Знания — сила»                             | «Композиции собираются только из исходных SVG. Ничего нового не рисуется».                            |
| 10–25 с | Создать и переключить три варианта                                       | «Локальный словарь выбирает предметы, компоновщик предлагает опору, диагональ и место под заголовок». |
| 25–38 с | Открыть объяснение, затем показать «Поймать ритм»                        | «Это объяснимые правила, не LLM. Неизвестные объекты не создаются».                                   |
| 38–52 с | Сменить формат, S/L и палитру                                            | «S/L — разные исходники. Размеры предметов меняются одним коэффициентом; геометрия сохраняется».      |
| 52–65 с | Переместить предмет, повернуть маркером с Shift, изменить слой, отменить | «Вариант можно довести вручную. Масштаб просмотра не меняет композицию».                              |
| 65–78 с | Экспортировать SVG, сохранить JSON и открыть его обратно                 | «Каждый предмет остаётся отдельной группой. Проект переносим вместе с исходниками».                   |
| 78–90 с | Показать три `examples/composition-*.svg` и сводку проверок              | «Горизонтальная, квадратная и вертикальная композиции. 192 проверки и 9 браузерных сценариев».        |

Три смысловых сценария:

1. **Рабочий стол / учёба** — персиковая горизонтальная композиция; книга держит группу, телефон опирается на неё, лампа уравновешивает высоту, ручка и пазлы добавляют детали.
2. **Музыкальная пауза** — лавандовый квадрат; наушники в фокусе, телефон как источник музыки, фоновые цветы без конкуренции за внимание.
3. **Финансовая подушка** — бирюзовая вертикаль; кошелёк и монета, фоновый телефон, свободная верхняя зона под внешний заголовок. Подушка как новый объект не рисуется.

Если нужно уложиться в 60 секунд: пропустить второй текстовый запрос и показ отдельных файлов в конце. Не называть словарь AI, не обещать универсальное понимание метафор и не заявлять ручную проверку обратного импорта в Figma.
