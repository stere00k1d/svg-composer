# Проверки — 2 ноября 2026

Проверки выполнялись локально на Windows, Node.js 24.22.1, Microsoft Edge через Playwright. Приложение никуда не публиковалось.

| Этап                         | Проверка                                        | Результат                                                                                              |
| ---------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Первый вертикальный сценарий | Импорт SVG → добавление → drag → скачивание SVG | Прошёл до расширения MVP; тот же браузерный сценарий повторно прошёл в финальном редакторе             |
| TypeScript и production      | `pnpm build`                                    | Успешно. Vite предупреждает о размере JS из-за встроенной исходной библиотеки (~1.95 МБ, ~589 КБ gzip) |
| Модель и SVG                 | `pnpm test`                                     | 74 проверки прошли                                                                                     |

| Исходные файлы               | `pnpm verify:sources`                           | SHA-256 всех 40 отдельных объектов совпадают с полученными текстами                                    |

Проверки SVG сравнивают геометрические атрибуты всех 46 источников (40 предметов и 6 фонов) до и после перекраски/экспорта. Проверены отдельные группы, отсутствие `<image>`, изоляция ID/CSS и локальных ссылок при повторных экземплярах, сохранение source, допустимые цвета, все девять комбинаций шаблонов/форматов, общий масштаб и обратимость смены формата. Текстовый сценарий проверен на неизвестном объекте, JSON — на восстановлении и повреждённых данных.

Браузерные сценарии проверяют:

1. S/L, поворот, дублирование, порядок слоёв, смену главного/фонового исходника, удаление и отмену; переход также выбирает правильный исходный фон S.
2. Сборку выбранных объектов, единый коэффициент адаптации, палитру, SVG, сохранение/открытие JSON и восстановление после перезагрузки.
3. Разбор текста с существующим телефоном и неизвестным драконом; неизвестный объект не появляется.
4. Загрузку пользовательской палитры, отказ от повреждённого JSON и SVG с растром.
5. Три демонстрации из собственных исходных компонентов, их SVG/JSON-файлы и мобильный экран.
6. Исходный вертикальный сценарий на импортированном SVG с ненулевым началом viewBox.

Выявленные и исправленные проблемы: накопительное уменьшение при смене формата, потеря отложенного автосохранения при перезагрузке, смешивание S/L в первоначальном выборе демо-компонентов. Тест перетаскивания дополнен прокруткой холста в видимую область после импорта нижней карточки.

После улучшения подбора числа колонок повторно прошли все 74 проверки модели/SVG и браузерный сценарий трёх демонстраций; соответствующие SVG/JSON перезаписаны. Финальная production-сборка также открыта во встроенном браузере: библиотека содержит 40 предметов, сценарий «Рабочий стол» собирает пять объектов и выбирает персиковую схему.

Не проверены вручную: обратный импорт в Figma, поведение в Firefox/Safari, большое число сложных фильтров и масок. Для собственного SVG с такими конструкциями требуется отдельная визуальная проверка. Структурная векторность экспорта подтверждена тестами; полная совместимость каждого редактора не заявляется.
